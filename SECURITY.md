# Security

Flip Watch runs entirely in your browser: files you open are processed on your
device and never uploaded anywhere. There is no backend, no account and no
analytics.

## Reporting a problem

If you find a security issue (for example an XSS in the PDF reader, or a case
where a file could leave the device), please open a private security advisory on
this repository, or email the maintainer listed on the GitHub profile. Please do
not open a public issue for it.

## Scope

- The static site in this repository and the GitHub Pages deployment.
- Third-party code vendored under `pdf-reader/vendor/` and `vendor/`.
