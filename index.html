Quick reference

How to use Calculator

Operators

+ add, − subtract, × multiply, ÷ divide, ^ power, % percentage, and ! factorial.

Examples: 25% = 0.25, 5! = 120, 2^8 = 256.

sin, cos and tan

These functions find the sine, cosine or tangent of an angle. In DEG mode, sin(30) = 0.5, cos(60) = 0.5, and tan(45) = 1.

Use them for triangle angles, slopes and height or distance calculations. tan(90) is undefined.

cosec, sec and cot

These are reciprocal trigonometric functions: cosec(x) = 1/sin(x), sec(x) = 1/cos(x), and cot(x) = cos(x)/sin(x).

Examples in DEG mode: cosec(30) = 2, sec(60) = 2, and cot(45) = 1. They are undefined when their denominator is zero.

Inverse trigonometric functions

These inverse functions return an angle from a sine, cosine or tangent value. They are useful for finding a missing angle in a triangle.

Examples in DEG mode: asin(0.5) = 30°, acos(0.5) = 60°, and atan(1) = 45°. acosec(x) = asin(1/x), asec(x) = acos(1/x), and acot(x) return the inverse of cosec, sec and cot.

asin and acos accept values from -1 to 1. acosec and asec require |x| ≥ 1; for example, acosec(2) = 30° and asec(2) = 60° in DEG mode. acot(1) = 45°.

sqrt, abs and exp

sqrt(x) finds the square root, abs(x) removes the negative sign to return distance from zero, and exp(x) calculates e^x.

Examples: sqrt(81) = 9, abs(-8) = 8, abs(10-18) = 8, and exp(1) = 2.71828....

ln and log

ln(x) is the natural logarithm with base e. log(value) is base 10 by default. Add a second value for another base: log(value,base).

Examples: ln(e) = 1, log(100) = 2, and log(8,2) = 3. The value and base must be positive, and the base cannot be 1.

GIF, LIF and round off

The GIF button runs floor(x) and rounds down. The LIF button runs ceil(x) and rounds up. round off runs round(x) and rounds to 2 decimal places.

Examples: floor(3.8) = 3, ceil(3.2) = 4, and round(3.14159) = 3.14.

mod and factorial

mod(a,b) returns the remainder after dividing a by b. The ! operator calculates factorial, the product of all positive integers up to a number.

Examples: mod(10,3) = 1 and 5! = 120. Factorial is for non-negative whole numbers.

DEG / RAD

DEG reads angles in degrees. Switch to RAD for radians: sin(pi/2) = 1, asin(0.5) = pi/6, and atan(1) = pi/4.

Constants and memory

π is pi, e is Euler's number, and Ans uses the last result. MC clears memory, MR recalls it, M+ adds to it, and M− subtracts from it.

Keyboard shortcuts

Type directly into the display. Press Enter to calculate, Escape to clear, and use parentheses for grouped calculations.

Example: (18+6)/3 + 2^3 = 16.
